# Cavalcante Premium Build

Crie um mini site premium, moderno e altamente chamativo para um Depósito de Materiais para Construção, totalmente responsivo (mobile-first), com aparência profissional, animações suaves e visual 3D elegante.

Identidade Visual

* Layout predominante em azul escuro (seguindo a cor da logomarca)

* Detalhes em laranja vibrante e branco

* Efeito glassmorphism

* Sombras suaves

* Bordas arredondadas

* Ícones modernos

* Aparência premium

* Rolagem extremamente fluida

* Todos os elementos surgem com animações elegantes conforme o usuário desce a página.

* Fundo com leves formas geométricas inspiradas em construção (linhas, vigas metálicas e plantas de obra em baixa opacidade).
